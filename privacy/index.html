Take It Out Uploader

Privacy Policy

Effective November 25, 2026

Take It Out Uploader uses YouTube API Services to operate the Take It Out Lab channel with the channel owner’s permission. This site provides information about that tool. Connecting the uploader happens through Google’s consent screen.

Data the uploader accesses

Google supplies authorization credentials when the channel owner connects the uploader. The uploader reads the channel ID and handle to verify the account. It reads video IDs, titles, release times, and visibility and processing status to schedule and verify uploads. It reads aggregate views, likes, comment counts, engaged views, average percentage viewed, and shares for the owner’s production review.

How data is used and stored

The uploader uses the credentials to connect to YouTube for these features. The credentials are stored in the owner’s local setup and as encrypted secrets in the private GitHub repository. GitHub Actions uses the credentials to run the uploader. Private release records and performance reports are stored in that repository. The rolling audit keeps up to 14 days of snapshots in its current file. Earlier versions can remain in private repository history until removed.

The owner’s Claude production task reads the private performance report to inform future episodes. The uploader uses Google user data for the channel operations described here. It does not sell it or use it for advertising.

Revocation and deletion

The channel owner can revoke the uploader’s access from Google Account permissions. Revocation stops the uploader from making new authorized requests. Use the contact below to request deletion of stored Google or YouTube data, including any copies that remain in private repository history.

Contact

For questions, complaints, or deletion requests, contact the uploader owner on GitHub. The issue is public. Use a generic subject and keep account details, credentials, or other private information out of the issue.

See Google’s Privacy Policy and the YouTube Terms of Service.
